# Creda — Project Guidelines & Mandates

## Core Principles
1. **Marketing Philosophy**: The website is a trust engine. Clearly answer:
   - Who we are (Creda: Proof-of-work skill passport for African tech talent)
   - What we do (Analyze GitHub code, commits, and CVs to issue cryptographic passports)
   - How to experience it (Interactive live ledger & preview directly on the page)
   - How to get started (Frictionless, free 60-second onboarding)
2. **Color Palette Discipline**:
   - Single brand accent color: Creda Cobalt/Indigo (`#4F46E5`).
   - Neutrals only (crisp whites, deep blacks, architectural grays).
   - Zero rainbow accents, zero neon text gradients, zero fuzzy floating orbs.
3. **Design Aesthetic (Oberon × AgentLab × Parley)**:
   - High-contrast editorial typography (editorial serif + modern grotesk + technical monospace).
   - Hairline grid borders with structural crosshairs (`+`).
   - Architectural proof artifacts instead of generic AI boxes.
4. **Zero-Clipping Layout**:
   - Never use `justify-center` on full-viewport flex containers.
   - Generous top padding (`pt-32` to `pt-36`) and ample vertical spacing (`py-24` to `py-32`).
